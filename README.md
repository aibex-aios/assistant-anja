# assistant-anja

Assistentin *Anja* von AIbex AIOS, Version 0.1.0: Spezialistin für die Entwicklung von AIOS-Paketen aller Typen (App, Assistent, Skill, Wissen, Tutorial, Distribution, Kernel). Sie kennt die Spec von AIOS v0.4, die Gründe dafür und die Praxis aus der Entwicklung von v0.4 und begleitet ein Paket vom ersten Gedanken bis zur Veröffentlichung. Jede Antwort beginnt mit „🙎🏻‍♀️ ".

```bash
aios --fetch assistant-anja
```

Zuordnen mit `/aios-assistant Anja` in dem Projekt, in dem die Pakete konzipiert werden.

## Wie Anja arbeitet

Anja folgt einem Workflow in zehn Phasen: Einstieg, Konzept, Bewertung, Konsolidierung in kleinen Fragegruppen, Soll-Bild und Skizze, Spezifikation, Freigabe, Implementierung, Abnahme und Rückblick. Im Konzept führst du oder sie, ganz wie du willst; danach führt sie und fragt immer mit einer Empfehlung. Jeder Übergang braucht dein Ja, alles wird in Memos festgehalten, und gebaut wird erst nach der Freigabe der Spezifikation.

## Voraussetzungen

Anja liest die Spec im Code-Repo `aibex-aios/aibex-aios` (je Version über den Tag) und die Gründe im Konzept-Repo `aibex-aios/AA-AIbex-AIOS`. Beide Repos sind derzeit privat; Anja hilft also vorerst nur Usern mit Zugriff (lokaler Klon oder `gh` mit Anmeldung).

## Vorgaben

Wo Paket-Repos liegen, in welchem Hub veröffentlicht wird und unter welcher Lizenz, legt jeder User selbst fest: in einer Regel *AIOS-Pakete — Vorgaben* (`name: aios-pakete-vorgaben`) im Masterspace des Konzeptprojekts. Ohne sie legt Anja Paket-Repos in `<projekt>/@Package/<paket>/` an und fragt den Rest, wenn er gebraucht wird.
